# 제작 페이지 켜기·끄기, "보냈어" 처리

프로그램은 저장소의 `10_제작페이지/`에 있다. 설계는 `00_공통문서/제작페이지_설계/기능명세_v001.md`.

## 켜기

1. 저장소 루트에서 서버를 **백그라운드로** 켠다(끝나지 않는 명령이다).

   ```bash
   PYTHONIOENCODING=utf-8 python 10_제작페이지/제작페이지.py --폴더 "<저장소 루트>"
   ```

   - 켜지면 사용자의 기본 브라우저가 열린다. 열지 않으려면 `--열지않음`.
   - 켜지면 `가마우지 제작 페이지: http://127.0.0.1:8765/` 줄이 찍힌다(그 앞에 `(포트 8765는 쓰이는 중이라…)` 같은 괄호 줄이 있을 수 있다). 8765가 쓰이는 중이면 다음 빈 포트를 쓰니, 찍힌 주소를 그대로 사용자에게 알린다.
   - 같은 폴더의 서버가 8765~8784 어디에든 이미 켜져 있으면 `이미 켜져 있습니다: <주소>`를 찍고 그 주소를 연 뒤 바로 끝난다(새로 켜지 않음).
2. 사용자에게 주소를 알린다. 이 주소는 이 PC에서만 열린다(127.0.0.1).
3. 사용자가 직접 켤 때는 `10_제작페이지/제작페이지_켜기.bat`을 두 번 누르면 된다. 그 창을 닫으면 꺼진다.

## 끄기

```bash
PYTHONIOENCODING=utf-8 python 10_제작페이지/제작페이지.py --폴더 "<저장소 루트>" --끄기
```

- 에이전트가 일하는 중("진행 중")인 단계나 점검하지 못한 캐릭터가 있으면 끄지 않고 알려 준다(종료 코드 1). 사용자에게 알리고, 그래도 끄라고 하면 `--그래도`를 붙인다. 서버가 실제로 꺼진 것을 확인해야 `껐습니다`가 찍힌다.
- 사용자가 서버 창에서 Ctrl+C를 누를 때도 같은 경우면 경고하고, 5초 안에 한 번 더 누르면 끈다. 창을 닫으면 경고 없이 바로 꺼진다.

## 단계 일을 시작하라고 하면

"3단계 메시 정리 시작해 줘"처럼 단계 일을 시작하라고 하면 `10_제작페이지/에이전트_안내.md`의 그 단계 절을 읽고 그 차례대로 한다(3단계는 두 번만 멈춘다: `메시진행`·`메시멈춤`).

## "보냈어"를 들으면

사용자가 페이지에서 칠하고 "보내기"를 누른 뒤 Claude 앱에서 "보냈어"라고 하면, **`10_제작페이지/에이전트_안내.md`를 먼저 읽고** 그 차례대로 한다. 요점:

1. `python 10_제작페이지/에이전트.py 받기 --캐릭터 <이름> --단계 <번호>` — 보낸 묶음을 받음(묶음 "처리 중")
2. 작업본을 바꾸기 전에 `사본` → 고침 → 모든 항목에 고침/안 고침 + 이유를 적은 파일로 `처리 <묶음> <파일.json>`(빠지면 거부됨)
3. `알림 "<한두 줄>"`, 작업본을 바꿨으면 `보기갱신`. 끝내지 못하면 `실패 <묶음> "<이유>"`

페이지 파일(`제작페이지/` 아래 JSON)은 손으로 고치지 않고 이 명령으로만 쓴다.

## 지키는 것

- 서버는 `127.0.0.1`에만 연다. 다른 주소로 여는 방법을 찾거나 만들지 않는다.
- 페이지와 서버는 바깥 주소로 요청하지 않는다(three.js 등은 `10_제작페이지/정적/lib/`에 있음).
- 페이지가 쓰는 파일은 캐릭터 폴더의 `제작페이지/`에 있다. 에이전트가 지킬 약속은 기능명세 1부 7절.
