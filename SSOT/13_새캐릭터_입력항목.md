# 새 캐릭터를 시작할 때 받는 것

## 한눈에 보기

- **새 캐릭터는 이 목록대로 받는다.** 제작 페이지의 "새 캐릭터" 입력 칸도 이 목록으로 만든다.
- **반드시 받는 것은 세 가지**: 컨셉, 헤어, 의상. 비율은 게임 공통이라 묻지 않는다.
- **나머지는 사용자가 적고 싶을 때만** 적는다. 비우면 에이전트가 컨셉에 맞게 제안하고 "에이전트 제안"으로 표시한다.
- **목록에 없는 요청은 "기타"에 적는다.** 기타에 적힌 것도 요청문에 빠짐없이 들어간다(빠뜨리지 않기, `AGENTS.md`).
- 받은 내용은 캐릭터 노트([[_새캐릭터_틀]])의 설정 표와 조립값으로 옮기고, 요청문은 `도구/요청문_조립.py`가 만든다([[11_이미지요청문_틀]]).

## 받은 뒤

1. 캐릭터 노트를 만들고 설정 표의 "상태" 칸에 사용자 지정 / 에이전트 제안 / 미정을 적는다.
2. 요청문을 조립한다.
3. **Codex에는 영어로 넘긴다**(사용자 결정, 2026-11-24). 영어 틀로 조립한 요청문을 넘기고, 한국어 조립본과 함께 기록한다([[11_이미지요청문_틀]]). 캐릭터 노트에 사용자가 한국어로 적은 값(컨셉·헤어·의상·기타)은 에이전트가 영어로 옮겨 캐릭터 노트의 영어 조립값 칸에 적고, 사용자 확인 화면에 한국어와 나란히 보인다.
4. Codex에 넘기는 것은 그림 생성에 필요한 설정뿐이다. 사용자의 이름·이메일·프로젝트 이야기는 넣지 않는다([[41_사용자_방침]] "승인이 필요한 일").
