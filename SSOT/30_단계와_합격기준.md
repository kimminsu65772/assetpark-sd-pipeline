# 단계별 순서와 합격 기준

## 한눈에 보기

- **순서는 이미지 → TRIPO → 메시 정리 → 텍스처 받기 → UV(Smart UV, 가다듬기) → 텍스처 정리 → 리깅 → Unity다**(사용자 결정 2026-11-23). TRIPO 텍스처 작업이 UV를 새로 펴기 때문에 텍스처를 받은 뒤 UV를 다루고, 그림 정리는 UV를 다 다듬은 뒤에 한다(고친 그림을 다시 옮겨 굽지 않도록).
- 노트 번호는 예전 순서대로 붙어 있다. 실제로는 [[5_텍스처]]의 받기(5-1~5-4)가 [[4_UV]]보다 먼저다. [[5_텍스처]]의 정리(5-5~5-7)는 [[4_UV]] 다음이다.
- **모든 단계는 스크립트로 다시 실행할 수 있어야 한다.** 사람이 편집기에서 손으로 하는 단계를 두지 않는다. Blender는 창 없이 실행한다.
- **단계마다 "끝났다는 표시"가 있다.** 수치만으로 통과시키지 않고, 그림을 직접 열어 본 뒤에 다음 단계로 간다([[40_검수와_보고]]).
- **스크립트는 지금 교복 사무라이의 폴더에 있고, 이 캐릭터에서 잰 값이 섞여 있다.** 새 캐릭터에 쓰려면 값을 다시 재거나 자동으로 찾게 바꿔야 한다. 공통 도구로 빼는 일은 캐릭터를 한두 개 더 해 본 뒤에 한다.
- 단계마다 순서·합격 기준·규격·겪은 시행착오를 한 노트에 모았다(아래 표). 세션은 자기 단계의 노트만 읽는다.

실행 꼴: `SSOT/도구/블렌더실행.sh <파일.blend 또는 -> <스크립트> [-- 인자]`(Git Bash). 창 없는 Blender를 돌리고 로그를 걸러 결과 줄만 보여 준다. 직접 부를 때는 `--python-exit-code 3`을 `--python`보다 앞에 둔다([[41_사용자_방침]] 작업 규칙)

단계 노트 1~3의 "끝났다는 표시"는 출처 문서에 그대로 있는 문장이 아니라, 교복 사무라이에서 한 일을 보고 SSOT를 만들 때 새로 적은 것이다(제안). 4~7단계의 표시는 출처의 "확인" 칸에서 옮겼다.

## 버전 관리

- 작업 파일은 캐릭터마다 blend 하나만 쓰고 새 버전 파일을 만들지 않는다. 한 단계를 마치면 기록하고 이름표(`vNNN`)를 붙인다. 기록·이름표·되돌리기는 사용자 지시가 있을 때 한다.
- 다른 세션이 같은 폴더를 쓴다. 자기가 바꾼 파일만 기록한다.
- 그림과 사본처럼 큰 파일은 git에 넣지 않는다(기록과 스크립트만). 디스크에만 있으니 지우지 않는다.
