# 4. UV

## 한눈에 보기

- **TRIPO 텍스처를 받은 뒤, TRIPO Smart UV를 네 파츠 한 파일로 1회 받고 Blender에서 필요한 부분을 가다듬는다.** UV가 바뀔 때마다 그림을 새 UV로 옮긴다(Smart UV는 그림을 옮겨 주고, Blender에서 가다듬은 뒤에는 옮겨 굽는다). 순서는 사용자 결정(2026-11-23, [[30_단계와_합격기준]]).
- **합격 수치(초안)**: 겹침 0(한 조각 안에서 접혀 겹친 것도 포함), 조각 사이 간격 8칸 이상(2048 기준), UV 0~1.
- TRIPO 실행 값은 [[2_TRIPO]] "TRIPO 값".

경로의 `B/`와 `…/SmartMesh_리깅보정/`은 `01_캐릭터/교복_사무라이/04_Blender/SmartMesh_리깅보정/`을 줄여 쓴 것이다. 실행 꼴과 버전 관리는 [[30_단계와_합격기준]].

## 순서와 합격 기준

순서(사용자 결정, 2026-11-23): [[5_텍스처]]에서 텍스처를 받아 작업본에 넣은 뒤, **TRIPO Smart UV**(`tripo mesh uv`, 그림 옮기기 켬, 문서상 20크레딧, 입력 삼각형 8만 이하)를 적용하고, Blender에서 필요한 부분을 가다듬어 그림을 옮겨 굽는다(`01_캐릭터/온천_검사/04_Blender/스크립트/텍스처옮겨굽기_v001.py`). 그 뒤 [[5_텍스처]]의 그림 정리로 간다(사용자 결정 2026-11-23). 온천 검사는 예전 순서(Smart UV `--no-bake` → 가다듬기 → 텍스처)로 했고, 텍스처 작업이 UV를 새로 펴서 옮겨 굽기로 맞췄다.

Smart UV를 받는 법(사용자 결정, 2026-11-23):
- 네 파츠를 객체로 나눈 채 **FBX 한 파일로 내보내 1회만** 보낸다(`도구/UV입력내보내기.py`, `WHOLE=전체`). 명령: `tripo mesh uv 전체.fbx --no-bake --json --yes -o <폴더>`. 비용은 파츠 수와 상관없이 1회분(20크레딧)이다. 실행 전 값·비용을 보여 주고 승인받는 것은 그대로다.
- 근거(온천 검사에서 파츠별 4회와 전체 1회를 비교): 전체로 보내도 파츠가 나뉜 채 돌아오고 파츠마다 0~1을 따로 쓴다. 형태·정점 순서는 입력과 같다. 파츠별로 보낸 쪽이 차지 비율·간격이 조금 나았지만 Blender에서 다시 배치하면 없어지는 차이이고, 이음매 자리는 파츠마다 장단이 있었다. 같은 입력을 두 번 보낼 때의 차이는 시험하지 않았다. 출처: `01_캐릭터/온천_검사/진행기록.md` "TRIPO Smart UV".
- 받은 결과는 크기가 정규화돼 올 수 있다(÷`normalize_scale`). 작업본에는 메시를 바꾸지 않고 UV만 옮긴다(정점 순서가 같으므로).
- 받은 직후 조사: `도구/SmartUV조사.py`(파츠 하나는 `PART=<객체이름>`). 이 스크립트는 아래에서 올려다보는 각도를 기본으로 찍지 않으니, 검수 그림에는 따로 더한다([[41_사용자_방침]] "치마 속"). 아래 표는 교복 사무라이에서 Blender로 직접 편 방법이며, 가다듬기와 점검에 쓴다.

| 순서 | 하는 일 | 스크립트 | 끝났다는 표시 |
| --- | --- | --- | --- |
| 4-1 | 이음매 기준으로 파츠마다 UV를 편다 | `B/시험/얼굴UV_v027/얼굴UV_다시펴기_v027.py`, `B/시험/몸UV_v027/몸UV_다시펴기_v027.py` | 겹침 0, 조각 사이 간격 8칸 이상(2048 기준), UV 0~1. 격자무늬와 조각 색 그림을 직접 봄 |
| 4-2 | UV 조사: 조각 수, 쓰는 자리, 겹침, 간격 | `B/스크립트/텍스처시험_UV조사_v001.py` | 안 보이는 면이 자리를 크게 차지하지 않음 |

기준은 아래 "UV 규격". 얼굴 UV 적용 스크립트는 예외로 멈춰도 종료 코드가 0이므로 출력의 완료 표시를 직접 확인한다.
