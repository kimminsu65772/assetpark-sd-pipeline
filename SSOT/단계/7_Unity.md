# 7. Unity 가져오기

## 한눈에 보기

- **동작을 이 캐릭터의 뼈대로 옮기고, 동작마다 치마를 구워 FBX로 내보낸 뒤 Unity에 Humanoid로 넣는다.**
- **클립마다 전체 뼈 마스크를 지정해야 치마 뼈의 움직임이 들어온다.**
- **함께 읽을 노트**: [[20_3D규격]](뼈대), 치마가 있으면 [[31_치마리깅_규격_초안]].

경로의 `B/`와 `…/SmartMesh_리깅보정/`은 `01_캐릭터/교복_사무라이/04_Blender/SmartMesh_리깅보정/`을 줄여 쓴 것이다. 실행 꼴과 버전 관리는 [[30_단계와_합격기준]].

## 순서와 합격 기준

| 순서 | 하는 일 | 스크립트 | 끝났다는 표시 |
| --- | --- | --- | --- |
| 7-1 | 다른 뼈대의 동작을 이 캐릭터의 뼈대(A자세)로 옮김 | `B/시험/유니티샘플_v033/동작옮기기.py` | 새 Action이 저장됨 |
| 7-2 | 동작마다 치마 굽기 | `B/시험/치마리깅_v032/굽기.py -- <Action 이름> <출력.blend>` | 동작마다 치마 곡선이 생김 |
| 7-3 | 교차 재기 | `B/시험/유니티샘플_v033/검수_재기.py` | 동작별 교차 수가 기록됨 |
| 7-4 | FBX 내보내기 | `B/시험/유니티샘플_v033/FBX내보내기.py` | `SchoolSamurai_v033.fbx` |
| 7-5 | FBX를 `Assets/Character/`에 넣고 Unity 설정: Humanoid, 텍스처 꺼내기, 클립마다 전체 뼈 마스크 | `unity run <프로젝트> -- -executeMethod GamaujiCheck.Setup` (`Assets/Editor/GamaujiCheck.cs`) | 치마 뼈의 움직임이 클립에 들어옴 |
| 7-6 | 자세를 찍고 뼈 사이 거리를 잼 | `GamaujiCheck.Capture`, `B/시험/유니티샘플_v033/거리재기.py` | Blender와 Unity의 거리 차이가 작음(교복 사무라이: 몸 뼈 최대 0.00004, 치마 뼈 최대 0.0017), 그림도 직접 봄 |
| 7-7 | Play 모드에서 재생하며 프레임을 찍어 GIF로 만듦 | `Unity.exe -batchmode -projectPath <프로젝트> -executeMethod GamaujiPlay.Run -logFile <로그>`, 이어서 프로젝트 폴더에서 `python Tools/make_gifs.py`. `unity run`은 Play 모드에 들어가기 전에 끝나므로 `Unity.exe`를 직접 실행한다 | 동작마다 GIF가 생기고 사용자가 봄 |

- `05_Unity전달` 폴더는 전달 준비 폴더다. 파일이 있다는 이유만으로 Unity 검수가 끝난 것으로 보지 않는다(`README.md`).

## 겪은 시행착오

| 무엇이 | 다음에는 |
| --- | --- |
| Humanoid로 가져오면 치마 뼈 곡선이 빠짐 | 클립마다 전체 뼈 마스크를 지정한다 |
| 자동 대응에 새끼손가락이 빠짐(Unity는 Little, 이 뼈대는 Pinky) | 이름으로 대응시킨다 |
| FBX를 가져오면 Blender 장면의 fps가 30으로 바뀜 | 가져오기 전의 값(24)으로 되돌린다 |
| 가져온 뼈대의 이름이 겹쳐 동작 이름이 달라짐 | 이름의 끝부분으로 찾는다 |
| 배치 모드에서 찍은 그림이 뼈 자세를 따라가지 못함(수치는 맞는데 그림은 다른 자세) | 자세마다 메시를 구워 고정 메시로 찍는다 |
| 맨 처음 찍는 한 장은 텍스처가 깨져 나옴 | 원인을 확인하지 못했다. 첫 장은 다시 찍는다 |
| 구르기에서 치마가 버티지 못하고 치마 속이 드러남 | 몸이 뒤집히는 동작은 구운 치마로 감당하지 못한다. 구르기는 쓰지 않기로 했다(사용자 결정, 2026-11-23). 뒤집히는 동작을 쓰려면 치마 속 처리가 먼저다 |
| `unity run`으로는 Play 모드를 찍지 못함 | Play 모드에 들어가기 전에 끝난다. `Unity.exe`를 직접 실행한다(위 7-7) |
| UniVRM 스프링본을 달자 자락이 원반처럼 펼쳐짐 | FBX 뼈의 크기 배율이 100으로 들어와 VRM이 충돌 반지름과 끝 뼈 가상 길이를 100배로 키움. `SSOT/도구/리깅/FBX내보내기.py`처럼 `apply_scale_options='FBX_SCALE_ALL'`로 배율 1로 내보낸다 |
