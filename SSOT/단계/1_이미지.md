합격 기준(확정): 기형이 남은 그림을 완성본·수정 성공본·TRIPO 입력으로 넘기지 않는다. 손가락 수만으로 손을 합격시키지 않는다. 출처: `00_공통문서/캐릭터_에셋_제작_기준.md` 0절, `AGENTS.md`.

등신이 게임 공통 범위(2.25~2.75) 안인지 확인하기 전에는 기준 그림 승인·후속 모델링으로 넘기지 않는다. 결과에 맞춰 허용 오차를 완화하지 않는다. 출처: 교복 사무라이의 조건(`01_캐릭터/교복_사무라이/캐릭터설정.md`)을 등신이 게임 공통이 되면서(사용자 결정, 2026-11-23) 모든 캐릭터에 적용한 것.

설정을 받고 제안하는 법(확정. 출처: 제작 기준 2절·3절)
- 체형은 자연어 묘사로 받고 숫자를 강제하지 않는다. 체형 수정은 승인된 기준 체형과 비교한다.
- 첫 생성 전에 모든 세부를 묻지 않는다. 충돌하거나 진행을 막는 것만 확인한다.
- 제안의 우선순위: 사용자 조건 준수 → 컨셉 전달 → 형태와 배색의 구분 → 작은 SD 캐릭터에서도 특징이 읽히는가 → 3D로 설명 가능한 구조인가 → 불필요한 장식을 줄였는가.
- 추가 제안에는 무엇을 추가했는지, 이유, 기존 조건에 미치는 영향을 기록한다.
- 생성된 그림에 등장했다는 이유만으로 추가 요소를 확정 설정으로 삼지 않는다. 설정화로 넘어갈 때 채택된 세부 디자인을 정리한다.

## 그림 검수 (확정)

- 정상 구조가 제1원칙이다. 구조 오류가 남았거나 사용자가 기형으로 지적한 결과는 미해결·탈락으로 기록한다.
- 손: 손별 부착, 엄지 위치, 손등/손바닥, 손목 연결을 보고, 앞뒤좌우에서 한 손을 돌린 관계인지 본다.
- 앞뒤 모습이 같은 실루엣을 복사한 그림인지, 표면·부착·가림이 실제 회전으로 설명되는지 대조한다.
- 자연스러운 가림은 허용한다. 안 보이는 부위를 정상으로 추측하지 않는다. 오류를 가리거나 방향마다 손목을 따로 돌려 요구를 채운 것처럼 만들지 않는다.
- 등신은 게임 공통 범위(2.5 ±10%, 2.25~2.75) 안인지 재고, 측정·추정 근거를 남긴다. 범위 안의 작은 차이는 수정 사유로 삼지 않는다.
- 탈락 결과와 구조 검수 전의 결과는 TRIPO 입력용으로 묶어 넘기지 않는다.
- 결함을 이미 설명받은 사용자가 탐색 실험용으로 쓰겠다고 밝힌 경우에는 최종 기준 승인과 구분해 기록한다. 실패한 그림의 사용을 에이전트가 대신 승인하지 않는다.
- 같은 모호함이 여러 버전에 반복되어도 구조가 타당하다는 근거로 삼지 않는다.
- 출처: `00_공통문서/캐릭터_에셋_제작_기준.md` 0절·4절, `AGENTS.md`, `00_공통문서/공통_검사및보고규칙_v001.md` 0절.

### 같은 게임의 캐릭터로 보이는가 (제안, 써 본 적 없음)

새 캐릭터의 기준 그림과 멀티뷰를 [[10_공통스타일]]의 스타일 참고 그림(교복 사무라이) 옆에 같은 발바닥 높이로 나란히 놓은 그림을 만들어 직접 본다.

| 볼 것 | 방법 |
| --- | --- |
| 등신, 머리와 몸의 크기 | 두 캐릭터의 정수리~턱, 정수리~신발 바닥을 재어 비교 |
| 얼굴이 서로 다른가 | 얼굴을 같은 크기로 확대해 나란히. 그리는 방식은 같고 생김새(눈매, 표정, 눈썹, 앞머리)는 달라야 한다. 같은 캐릭터의 스킨이면 반대로 같아야 한다 |
| 손발의 단순화 정도 | 손과 신발을 확대해 나란히 |
| 선과 채색 방식 | 전신을 나란히 |

색과 질감의 차이는 이 단계의 탈락 사유로 삼지 않는다(3D에서 맞춘다). 판정은 사용자가 그림을 보고 한다.
