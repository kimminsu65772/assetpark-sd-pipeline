# 3. 메시 정리

## 한눈에 보기

- **처음 정리 → 파츠 분리 → 대칭 → 접합부 검사 순서다.** 접합부 수정은 대칭 뒤에 한다.
- **결함 후보는 그림과 근거로 먼저 보여 주고, 승인한 것만 지우거나 고친다.**
- **함께 읽을 노트**: [[20_3D규격]](크기·뼈대·파츠). 고친 뒤 점검은 [[40_검수와_보고]] 4절.

경로의 `B/`와 `…/SmartMesh_리깅보정/`은 `01_캐릭터/교복_사무라이/04_Blender/SmartMesh_리깅보정/`을 줄여 쓴 것이다. 실행 꼴과 버전 관리는 [[30_단계와_합격기준]].

## 순서와 합격 기준

순서 초안(교복 사무라이에서 거친 순서를 정리한 것. 다른 모델 1~2개에서 반복된 뒤 확정):

1. 가져오기와 구성 조사
2. 처음 정리: 떠 있는 조각, 아주 작은 잔여 조각, 캐릭터 설정에 없는 덧붙은 메시
3. 파츠 분리(헤어 / 얼굴 / 상체 / 하체)
4. 대칭으로 만들 조각과 비대칭으로 둘 조각 정하기
5. 파츠별 대칭 중심 재기
6. 좌우 절반을 비교해 기준 쪽 고르기
7. 대칭으로 만들고 이음선 점검
8. 중심 정렬과 통합
9. 대칭 상태에서 남은 결함 정리: 접합부 검사, 파츠 검사 후보
10. 노멀 다시 계산(교복 사무라이에서는 하지 않았다)

- 접합부 수정은 대칭 뒤에 한다(대칭보다 먼저 했다가 한쪽 수정이 버려진 적이 있다).
- 결함 후보는 그림과 근거로 먼저 보여 주고 승인한 것만 지우거나 고친다. 정지 자세만 기준으로 한다.
- 노이즈 조각은 공통 도구 `SSOT/도구/메시검사.py`의 조각 목록으로 찾는다(쓰는 법은 파일 머리말). 처음 정리(2)에서 TRIPO 원본에 돌려(`--객체 <원본 객체>`), 서로 이어지지 않은 조각을 전부 한 칸씩 본다. 입력 그림에 없는 조각이 노이즈다. 수치로 거르지 않는다. 에이전트가 칸 그림을 직접 보고 1차로 거르고(뺀 것은 이유를 기록), 남은 것만 그림과 함께 사용자에게 보인다(사용자 결정 2026-11-23: 사람이 모든 모델을 다 보기는 어렵다). 교복 사무라이의 눈·속눈썹·눈썹 메시 8덩어리가 이 방법으로 모두 한 칸씩 나왔다.
- 아주 작은 면, 작은 구멍, 겹친 변, 패임·돌출, 가려진 면은 `--검사 전부`로 함께 낸다. 원래 모양이 훨씬 많이 걸리므로(온천 검사 74개 중 노이즈 0) 대칭 뒤(9)에 참고로 본다(제안). 근거의 `보이는면_비율`이 0이면 바깥 어디서도 안 보이는 자리다. 기준값(미세 면 2e-6 × 높이², 이웃 대비 0.08, 요철 0.010 × 파츠 대각선 등)은 교복 사무라이에서 정한 초안이다.
- 그 밖의 도구(교복 사무라이 전용 값이 박혀 있음): `B/스크립트/`의 `접합부지도_v001.py`, `접합부검사_v001.py`, `조각묶음_구조조사_v001.py`, `비교캡처_v001.py` 등(목록과 인자는 출처 8절).
- 끝났다는 표시: 접합부별 판정이 기록되고, 정지 자세의 여러 방향 그림에서 눈에 띄는 결함이 없으며, 단계마다 git 이름표(`vNNN`)가 붙음.
- 도구의 한계: 메시검사의 조각 목록은 몸통에 이어 붙은 덧붙은 메시(교복 사무라이의 눈 위 덧붙은 겹 같은 것)는 잡지 못한다. 결함 후보는 정지 자세에서 파츠 하나 안의 결함만 본다(가림은 모든 파츠를 넣고 본다). 눈 자리 정도의 얕은 굴곡은 잡지 못한다. 접합부검사는 열린 테두리, 한 변에 면이 3개 이상 붙은 곳, 삐져나온 면만 후보로 올리고 면끼리 서로 뚫는 곳은 잡지 못한다. 검사 기준값(가까움 0.012 등)은 에이전트가 정한 값이며 확정 규칙이 아니다. 모든 검사는 정지 자세 기준이다.
- 노멀을 통째로 다시 계산하면 니삭스 윗단의 선 같은 디자인 요소가 흐려진다. 그때는 날카로운 변으로 지정한다.
- 노멀은 TRIPO가 준 것을 기본으로 두고, 음영이 이상한 부위만 고친다([[41_사용자_방침]] "노멀"). 온천 검사에서 게타 바닥판을 이렇게 고쳤다(꺾임 30도 기준, `01_캐릭터/온천_검사/04_Blender/스크립트/게타노멀_v001.py`). 몸 전체를 80도 기준으로 다시 계산한 비교는 `01_캐릭터/온천_검사/04_Blender/메시정리_v001/08_노멀비교/`에 있다.
- 대칭으로 뒤집을 때는 사용자 지정 노멀도 함께 뒤집는다(`01_캐릭터/온천_검사/04_Blender/스크립트/대칭도구.py`). 중심선 근처 정점을 붙이는 거리는 파츠마다 확인한다(온천 검사의 뒷머리는 0이어야 했다).
