## 조립값 (기계가 읽는 부분)

블록 이름은 바꾸지 않는다. 문장은 [[교복_사무라이]]의 것을 본으로 삼는다. 머리말의 `등신`은 비워 둔다([[10_공통스타일]]의 게임 공통값을 쓴다). `컨셉초안`과 `기준그림`은 그림이 생기면 저장소 루트 기준 경로로 적는다.

```조립 캐릭터.소개
(예: 오리지널 ○○이다.)
```

```조립 캐릭터.헤어와의상
- (헤어)
- (상의·하의)
- (눈에 띄는 색과 장식)
- (양말·신발)
```

```조립 캐릭터.이어지는부위
(방향이 바뀌어도 같은 물건으로 이어져야 하는 부위를 쉼표로)
```

```조립 캐릭터.제외
- (따로 만들 소품)
- (미확정 장식)
```

## 영어 조립값 (Codex에 넘기는 것)

Codex에는 영어 요청문이 넘어간다([[11_이미지요청문_틀]] "영어 요청문"). 위 블록마다 이름 앞에 `영어.`를 붙인 블록을 두고, **위 한국어 블록과 줄 수·줄 모양(`- `, 빈 줄)·숫자를 맞춰** 줄마다 옮긴다. 사용자가 한국어로 적은 값은 에이전트가 옮기고, 사용자 확인 화면에 한국어와 나란히 보인다([[13_새캐릭터_입력항목]]). 짝이 어긋나면 조립 도구가 멈춘다.

```조립 영어.캐릭터.소개
(e.g. an original ○○.)
```

```조립 영어.캐릭터.헤어와의상
- (hair)
- (top and bottom)
- (notable colors and decorations)
- (socks and shoes)
```

```조립 영어.캐릭터.이어지는부위
(parts that must stay the same object across views, separated by commas)
```

```조립 영어.캐릭터.제외
- (props made separately)
- (undecided decorations)
```
